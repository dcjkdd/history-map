# 核心数据模型

## 1. 核心实体

```text
Topic       专题
Period      历史时期
Place       历史地点
PlaceName   地名沿革
Person      人物
Event       历史事件
Battle      战役
Route       路线
RouteNode   路线节点
Source      资料
Citation    引用
```

## 2. Place：历史地点

建议字段：

```text
id
canonical_name
modern_name
place_type
longitude
latitude
geom
valid_from
valid_to
description
confidence_level
created_at
updated_at
```

`place_type`：

```text
CITY       城池
PASS       关隘
FORT       堡垒
BATTLE     古战场
MOUNTAIN   山脉
RIVER      河流
ROAD       古道
FERRY      渡口
GRANARY    粮仓
CAMP       军营
REGION     区域
```

## 3. PlaceName：地名沿革

```text
id
place_id
historical_name
dynasty
start_year
end_year
name_type
source_id
```

同一个地理实体在不同时期可能有不同名称，不能只在 Place 表放一个字符串。

## 4. Event：历史事件

```text
id
topic_id
title
event_type
start_date
end_date
summary
importance
certainty
```

事件可关联多个地点、人物、战役和引用。

## 5. Route 与 RouteNode

```text
Route
- id
- topic_id
- name
- route_type
- person_id / force_id
- start_date
- end_date
- description

RouteNode
- id
- route_id
- place_id
- sequence_no
- arrival_date
- departure_date
- action_type
- certainty
- citation_id
```

路线不能只存一条 LineString，还要保留节点、顺序、时间和来源。

## 6. Source 与 Citation

```text
Source
- id
- title
- author
- edition
- publisher
- publish_year
- source_type
- copyright_note

Citation
- id
- source_id
- chapter
- page_start
- page_end
- quote
- summary
- viewpoint_type
- certainty
```

引用可以关联地点、人物、事件、战役和路线节点。

## 7. 时间字段原则

历史时间可能只有年份、月份或大致范围，因此不应只用标准日期强行表达。

建议同时保存：

- 标准化开始和结束时间（可空）
- 原始历史时间文本
- 时间精度：YEAR / MONTH / DAY / APPROXIMATE
- 时间可信度
