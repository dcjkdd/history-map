# 地图数据与图层

## 1. 几何类型

| 数据 | 几何类型 |
|---|---|
| 城池、关隘、渡口、战场 | Point |
| 河流、古道、路线、长城 | LineString / MultiLineString |
| 行政区、势力范围、战区 | Polygon / MultiPolygon |
| 山脉和地形 | DEM / Raster / Terrain Tiles |

## 2. 坐标系统

业务交换和前端展示主要使用 WGS84（EPSG:4326）。

空间距离和面积计算时，应根据范围选择适合的投影坐标系，不能直接把经纬度差值当公里。

## 3. 地图数据来源原则

- 优先使用有明确授权和出处的数据
- 保留原始来源、处理过程和许可证
- 不把现代行政中心直接当作古代城址
- 不确定地点必须标注可信度和范围
- 古代疆域不能凭视觉印象手画

## 4. 图层展示规则

### 缩放级别

- 全国视野：只显示核心城市、主要河流、重要战役
- 区域视野：显示关隘、古道、渡口和次级城池
- 局部视野：显示路线节点、营地、桥梁、粮仓等

### 标记语义

- 城池：圆点或城池图标
- 关隘：城门图标
- 战役：旗帜或交叉兵器
- 渡口：船或水路节点
- 路线：带方向的线
- 争议位置：虚线边框或半透明范围

## 5. 数据服务演进

### 小数据量

Go 查询 PostGIS，返回 GeoJSON。

### 中大数据量

Martin 从 PostGIS 输出 MVT，静态数据可进一步使用 PMTiles。

### 地形

- PHASE2-02 正式方向为 Copernicus GLO-90 区域离线派生；15 个原始 COG 不进入仓库。
- 当前正式资产为 1800×1080 分层设色 PNG、78 张 z5—9 Terrarium PNG 和现代河南/陕西 GeoJSON，总计 `9,572,150 bytes`；已随 PHASE2-02 提交 `ab3ac2d` 推送。
- MapLibre 默认以俯视分层设色 + hillshade 加载；失败时历史层可读但必须显示降级，不得视为产品通过。
- 来源、逐文件 SHA-256、许可、署名、再生成和体积预算见 [PHASE2-02 地形资产记录](phase2-02-terrain-assets.md)。
- 河南、陕西边界只用于现代定位；不进入正式历史 JSON，也不表示唐代边界。

### PHASE2-03 军事地理显示

- 新增运行时 GeoJSON source `phase2-military-geography-guides`，只包含现代流向箭头、现代低地标签锚点和两点解释性通道；它不写入正式历史 JSON。
- 黄河、渭河流向副本沿既有正式 Geography 坐标顺序显示，符号层使用箭头；正式行动路线继续使用独立虚线图层且没有箭头。
- 关中东部低地锚点为 `[109.68, 34.40]`，没有 Polygon；东入关中通道将 `route-tang-advance-01` 两点反转并使用 `22px` 屏幕带宽，不表示真实宽度、古道或路线。
- 图层顺序为地形、通道底带、正式地理、流向/低地/通道标签、正式路线、地点；水系与山地/低地/通道分别开关，`style.load` 后幂等重建。
- 潼关保留正式 `PASS / DISPUTED / LOW` 数据和不确定性圆，使用菱形符号，与城市、战场不只靠颜色区分。
- 来源、人工审核、精确处理记录、许可与验证边界见 [PHASE2-03 军事地理展示记录](phase2-03-military-geography.md)。
