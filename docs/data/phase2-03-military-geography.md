## 3. 运行时几何清单

运行时统一生成 GeoJSON source `phase2-military-geography-guides`，不向正式历史 JSON 新增实体。

| 展示对象 | 几何与处理 | 宽度/符号 | 可追溯边界 |
|---|---|---|---|
| 黄河、渭河流向提示 | 逐字复制正式 Geography 中对应 `LineString` 的坐标顺序，仅生成重复箭头符号 | 箭头文字 `➤`，沿线间距 `150px` | 只表示获批的现代概览方向；路线仍是独立虚线且没有箭头 |
| 关中东部低地标签 | `Point [109.68, 34.40]`，仅作为显示锚点 | 文本标签，无面几何 | 不表示历史边界、面积或通行范围 |
| 东入关中解释性通道 | 将正式 `route-tang-advance-01` 的两点坐标反转，得到灵宝代表点至潼关代表点：`[[110.872607, 34.615468], [110.2909781, 34.6035548]]` | `22px` 半透明屏幕带 + `2.2px` 虚线边缘 | 两点线只是东西关系的显示骨架；`22px` 不是地面宽度，不发布为历史道路或路线 |
| 潼关 | 继续使用正式 `place-tongguan` 点及其不确定性圆 | `◆` 关隘符号，与城市圆点、战场符号形状不同 | `type=PASS`、`confidence=LOW`、`locationStatus=DISPUTED` 保持不变 |

图层顺序为：正式地形 → 通道底带 → 正式河流/秦岭 → 流向、低地及通道标签 → 正式行动路线 → 地点。四组开关分别控制水系、山地/低地/通道、地点和路线；`style.load` 后按相同顺序幂等重建。
