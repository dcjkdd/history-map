# 史料引用与数据可信度

## 1. 为什么必须保存可信度

历史地图经常存在：

- 古城址位置只能大致确定
- 同名地点对应多个候选位置
- 行军日期来自后世推算
- 兵力数字在不同史料中差异巨大
- 现代学者对事件原因有不同解释

系统不能把所有内容都展示成确定事实。

## 2. 推荐可信度等级

```text
HIGH       多个可靠来源一致，位置或事实较明确
MEDIUM     有主要来源支持，但存在小范围误差或解释差异
LOW        仅有单一或较晚来源，存在明显争议
DISPUTED   有多个互相冲突的主要观点
UNKNOWN    暂无足够证据
```

## 3. 观点类型

```text
FACT                可较明确确认的事实
PRIMARY_RECORD       原始或传统史书记载
MODERN_RESEARCH      现代学者研究观点
LATER_NARRATIVE      后世文学或宣传叙事
INFERENCE            项目根据资料进行的推断
DISPUTE              存在争议
```

## 4. 稳定定位与页码选择

1. 正史与编年史优先使用“书名·卷次·纪传/年条”等跨版本相对稳定的内部定位；同时记录实际使用的版本、稳定 URL 和访问日期，不能只写书名。
2. 现代研究著作若没有稳定内部编号，使用“版本 + 章节 + 页码”定位。
3. 没有页码时可以使用可独立复核的稳定定位，但不能写“相关章节”“网络资料”等模糊描述。
4. 无论采用页码还是稳定定位，都以项目归纳为主；原文摘录只保留短小且确有必要的片段。

## 5. 前端展示建议

每条说明可显示：

- 结论
- 类型
- 可信度
- 引用资料
- 页码或稳定定位
- 是否存在其他观点

例如：

```text
位置：唐潼关故城附近
可信度：中
说明：古代关城位置和现代景区并非完全重合
来源：……
```

## 6. 数据录入原则

1. 原文、归纳和推断分开保存。
2. 不修改原文以适配自己的结论。
3. 一个结论可以关联多个引用。
4. 一条 Citation 可以支撑多条不同 Claim，但每条 Claim 仍必须显式绑定实际支持它的 Citation，不能只在实体级笼统挂来源。
5. 冲突观点并列展示，不强行合并。
6. 所有坐标修改保留修订记录。
