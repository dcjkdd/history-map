# 本地环境检查

> 当前地形优先第二期继续复用静态前端执行环境，范围以 [ADR-0002](../decisions/0002-地形优先二期产品纠偏.md) 为准。Go、Docker 和 PostGIS 属于后端化阶段，不是当前产品阶段的启动条件。

## 1. 当前静态 MVP 必需软件

- Git
- Node.js 24.18.0（由根目录 `.nvmrc` 固定）
- npm
- IDE：GoLand / IDEA / VS Code 均可

QGIS 是正式地点和路线几何核对的离线工具；不进入应用运行时，但在正式内容发布前需要安装并完成几何检查。

## 2. 检查命令

```bash
nvm use
node -v
npm -v
git --version
```

预期 Node 输出为 `v24.18.0`。

## 3. 内容准备建议

- QGIS LTR
- GDAL
- Python 3

## 4. 当前 MVP 暂时不需要

- Go
- Docker Desktop
- PostgreSQL / PostGIS
- Kubernetes
- Kafka
- Elasticsearch
- Redis
- 独立向量数据库
- GPU
- 微服务注册中心

后端化阶段再按需要安装 Go、Docker Desktop、psql 和数据库工具。

## 5. 推荐本地目录

```text
/Users/banq/Documents/history-map
```

README、`docs/`、`frontend/`、`data/` 等目录均直接位于该项目根目录；不要再创建 `history-map-docs/` 嵌套目录。

## 6. 后续环境初始化建议

```bash
cd /Users/banq/Documents/history-map

nvm use

cd frontend
npm create vite@latest . -- --template vue-ts
```

Go、Docker Compose 和数据库初始化脚本留到后端化阶段。
