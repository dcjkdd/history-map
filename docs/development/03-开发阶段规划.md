# 开发阶段规划

> 文档定位：长期演进规划。当前先执行 [静态前端 MVP 计划](../plans/mvp-scope.md)，决策依据见 [ADR-0001](../decisions/0001-静态前端MVP优先.md)。下述“第零期”调整到静态 MVP 验证通过后再启动。

## 第零期：项目骨架与数据设计

目标：项目能启动，核心数据模型稳定。

- 建立 Git 仓库和目录
- 创建 Vue 和 Go 项目
- Docker Compose 启动 PostGIS
- 建立数据库迁移
- 定义地点、人物、事件、战役、路线、资料和引用模型
- 建立安史之乱专题

交付标准：

- 前后端可以启动
- 数据库可以初始化
- 能保存并查询一个地点

## 第一期：二维可用版

目标：形成完整可用的安史之乱地图雏形。

- MapLibre 基础地图
- 地点、关隘、战场标记
- 河流和路线图层
- 图层开关
- 地点详情面板
- 安史之乱时间轴
- 行军路线逐段展示
- 资料来源和页码
- 简单数据维护页面

交付标准：

- 可以通过时间轴理解主要事件顺序
- 可以点击地点查看历史作用和资料出处
- 可以展示 5—10 条核心路线

## 第二期：三维地形与军事地理

- DEM 高程数据
- MapLibre 3D Terrain
- 山体阴影
- 地形分层配色
- 主要山脉、河谷、关隘和古道
- 战役地形讲解
- 路线坡度和通道关系（按需）

交付标准：

- 能直观看出关隘和路线的地形原因
- 潼关专题形成完整地形讲解

## 第三期：知识库与自动导入

- PDF / EPUB / Markdown 上传
- 文档解析和切片
- pgvector
- 地点、人物、年份实体提取
- 人工确认流程
- 带引用 AI 问答
- 多资料观点对比

交付标准：

- 地图点击地点可以检索相关书籍段落
- AI 回答包含资料、章节和页码

## 第四期：专题扩展

优先扩展安史之乱内部专题：

- 潼关之战
- 睢阳保卫战
- 两京收复
- 郭子仪和李光弼
- 邺城战事
- 藩镇格局

再扩展其他时代：

- 三国
- 楚汉战争
- 宋金战争
- 明末战争

## 第五期：协作与公开发布

- 用户账号
- 私有笔记
- 数据修订记录
- 争议地点讨论
- 审核发布流程
- 搜索引擎与公开访问策略
