# 安史之乱专题规划

## 1. 范围

时间范围：755—763 年。

首版不追求覆盖所有事件，重点打通：

- 范阳起兵
- 河北与河东战线
- 洛阳陷落
- 潼关防线
- 长安陷落与玄宗入蜀
- 肃宗灵武即位
- 睢阳防御
- 两京收复
- 邺城相关战事

## 2. 核心地点

### 城池和区域

- 长安
- 洛阳
- 范阳 / 幽州
- 太原
- 灵武
- 睢阳
- 邺城
- 常山
- 平原
- 陈留
- 陕州
- 南阳

### 关隘、渡口与战略节点

- 潼关
- 函谷关
- 蒲津关
- 井陉
- 雁门关
- 灵宝
- 河阳桥
- 马嵬
- 剑门

具体坐标和名称必须基于资料校正，不能仅按现代同名地点直接替代。

## 3. 核心路线

- 安禄山：范阳向河北、中原、洛阳推进
- 叛军：洛阳向陕州、潼关方向推进
- 唐玄宗：长安经马嵬、陈仓、剑门入蜀
- 唐肃宗：从西北方向前往灵武
- 郭子仪、李光弼在河北和河东的军事行动
- 张巡、许远与睢阳防御线

路线数据需要拆成节点，并记录：

- 顺序
- 预计日期
- 人物或军队
- 行动类型
- 资料来源
- 时间和路线可信度

## 4. 第一版展示重点

第一版重点讲清楚一个问题：

> 为什么潼关是长安东面的关键防线，以及哥舒翰出关后战略局势为何迅速恶化？

围绕它展示：

- 长安、洛阳、陕州、灵宝、潼关的空间关系
- 黄河、渭河、秦岭和山地通道
- 防守方和进攻方路线
- 时间节点
- 史料和现代研究观点

### 当前第一可用产品的最低形态

2026-08-02 产品纠偏后，上述“展示”不得再由中性平面上的几个点和直线代替。第一可用产品至少必须同时提供：

- 可读的高程、山体阴影或分层设色，让用户不读长文也能辨认山地、河谷和平原；
- 省级或同等清晰的现代方位参照，让用户知道专题发生在今天的大致区域；
- 黄河、渭河、秦岭、关中平原、崤函—潼关通道等与叙事直接相关的标注；
- 把潼关表现为受山河与通道共同约束的关隘，而不是普通地点点位；
- 洛阳—陕州—灵宝—潼关—长安的方向、节点关系和大致距离；
- 对路线、坐标、历史地貌对应和军事解释的不确定性提示。

地图是主叙事，时间轴和详情是辅助证据。具体范围和阻断条件见 [第二期地形优先范围](../plans/phase-2-terrain-scope.md) 与 [第二期验收标准](../plans/phase-2-terrain-acceptance.md)。
