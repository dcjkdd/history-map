# 竞品与差异化

## 1. 已有产品类型

市面上已有的相关产品大致分为：

1. 历代疆域时间轴地图
2. 中国历史 GIS 学术数据库
3. 历代战争图集数字化产品
4. 世界史动态地图
5. 单场战役路线图
6. 普通古今地名查询工具

这些产品证明历史地图有明确需求，但通常只覆盖以下一部分：

- 疆域变化
- 历史事件点
- 战争图集
- 行军路线
- 行政区划

## 2. 项目差异化

### 用地形解释战争

不只标记地点，还解释山脉、河流、关隘、渡口、粮道和道路的战略作用。

### 古今地名与时间有效期

同一地点可以在不同历史时期显示不同名称，不把古代地点简单等同于现代城市中心。

### 动态战役过程

通过时间轴逐步显示：

- 军队移动
- 城池得失
- 主将位置
- 战线变化
- 事件与史料

### 史料驱动

每个重要结论可追溯到：

- 原始史料
- 现代研究
- 章节和页码
- 观点类型
- 争议说明

### 专题深度

不先做一个浅层的“中国五千年地图”，而是先把安史之乱一个专题做深，再复用模型扩展。
