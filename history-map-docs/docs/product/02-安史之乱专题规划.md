# 安史之乱专题规划

## 1. 范围

时间范围：755—763 年。

首版不追求覆盖所有事件，重点打通：

- 范阳起兵
- 河北与河东战线
- 洛阳陷落
- 潼关防线
- 长安陷落与玄宗入蜀
- 肃宗灵武即位
- 睢阳防御
- 两京收复
- 邺城相关战事

## 2. 核心地点

### 城池和区域

- 长安
- 洛阳
- 范阳 / 幽州
- 太原
- 灵武
- 睢阳
- 邺城
- 常山
- 平原
- 陈留
- 陕州
- 南阳

### 关隘、渡口与战略节点

- 潼关
- 函谷关
- 蒲津关
- 井陉
- 雁门关
- 灵宝
- 河阳桥
- 马嵬
- 剑门

具体坐标和名称必须基于资料校正，不能仅按现代同名地点直接替代。

## 3. 核心路线

- 安禄山：范阳向河北、中原、洛阳推进
- 叛军：洛阳向陕州、潼关方向推进
- 唐玄宗：长安经马嵬、陈仓、剑门入蜀
- 唐肃宗：从西北方向前往灵武
- 郭子仪、李光弼在河北和河东的军事行动
- 张巡、许远与睢阳防御线

路线数据需要拆成节点，并记录：

- 顺序
- 预计日期
- 人物或军队
- 行动类型
- 资料来源
- 时间和路线可信度

## 4. 第一版展示重点

第一版重点讲清楚一个问题：

> 为什么潼关是长安东面的关键防线，以及哥舒翰出关后战略局势为何迅速恶化？

围绕它展示：

- 长安、洛阳、陕州、灵宝、潼关的空间关系
- 黄河、渭河、秦岭和山地通道
- 防守方和进攻方路线
- 时间节点
- 史料和现代研究观点

## 5. 数据量目标

- 30—50 个地点
- 20—30 个人物
- 30—60 个事件
- 5—10 条核心路线
- 5—10 场重点战役
- 1—3 本核心资料的结构化摘录与笔记
