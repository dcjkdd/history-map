# 产品定位与核心功能

## 1. 产品定位

一个用真实地形解释中国古代战争的交互式历史地图。

它不只回答“发生在哪里”，还要回答：

- 为什么必须经过这个关口？
- 为什么这座城是兵家必争之地？
- 山脉和河流如何限制军队移动？
- 粮道、渡口和古道如何影响胜负？
- 不同史料对同一事件有何差异？

## 2. 核心图层

| 图层 | 内容 | 第一版 |
|---|---|---|
| 地形 | 高程、山脉、盆地、平原 | 二期增强 |
| 水系 | 黄河、长江、渭河、汾河、汉江等 | 是 |
| 城池 | 古代名称、现代位置、名称沿革 | 是 |
| 关隘 | 潼关、函谷关、井陉、剑门关等 | 是 |
| 古道 | 驿道、蜀道、河西走廊、秦直道等 | 部分 |
| 战役 | 战场位置、时间、双方、结果 | 是 |
| 路线 | 进军、撤退、补给和逃亡路线 | 是 |
| 疆域 | 某一时期的行政区和控制范围 | 后期 |
| 史料 | 书籍、章节、页码、观点 | 是 |

## 3. 关键交互

### 时间轴

- 按年、月或事件节点播放
- 路线逐段出现
- 城池状态发生变化
- 人物位置变化
- 右侧同步显示事件和出处

### 点击地点

显示：

- 历史名称和现代位置
- 地点类型
- 所处山脉、河流和通道
- 历史作用
- 相关战役、人物、路线
- 资料引用
- 坐标可信度

### 点击人物

高亮：

- 活动地点
- 行军路线
- 参与战役
- 事件时间轴

### 点击战役

展示：

- 战场地形
- 参战方和主将
- 兵力与数字可信度
- 进军与撤退路线
- 战役过程
- 胜负原因
- 不同史料观点

## 4. 长期功能

- 多专题切换
- 朝代和年份筛选
- 古今地名搜索
- 书籍知识库问答
- 不同学者观点对比
- 用户读书笔记
- 地图数据后台维护
- 争议坐标和争议观点协作修订
