# 前端技术栈

## 1. 推荐组合

- Vue 3
- TypeScript
- Vite
- Vue Router
- Pinia
- MapLibre GL JS
- ECharts
- Element Plus 或 Naive UI

## 2. MapLibre GL JS 的职责

- 二维地图展示
- 地图缩放、旋转和倾斜
- GeoJSON 图层
- 矢量瓦片图层
- 城池、关隘、战场标记
- 河流、道路和行军路线
- 图层开关
- 后期三维地形和山体阴影

相比 Leaflet，MapLibre 更适合三维地形、WebGL、大量动态图层和矢量瓦片。

## 3. ECharts 的职责

ECharts 不负责主地图，主要用于：

- 战役时间轴
- 人物关系
- 兵力或事件变化
- 资料观点对比
- 专题统计信息

## 4. deck.gl

第二阶段以后按需加入，用于：

- 大量路线
- 动态箭头和粒子效果
- 大规模点图层
- 热力和聚合展示

第一版不引入，避免增加复杂度。

## 5. 主要页面

```text
/map                 主地图
/topic/:topicId      专题页
/place/:placeId      地点详情
/battle/:battleId    战役详情
/person/:personId    人物详情
/admin               数据维护后台
```

## 6. 地图状态

Pinia 可维护：

- 当前专题
- 当前年份或时间节点
- 已开启图层
- 当前选择的地点、人物或战役
- 地图视野和缩放级别
- 时间轴播放状态
