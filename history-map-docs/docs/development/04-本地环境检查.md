# 本地环境检查

## 1. 第一阶段必需软件

- Git
- Go
- Node.js
- Docker Desktop
- QGIS
- IDE：GoLand / IDEA / VS Code 均可

PostgreSQL 和 PostGIS 推荐使用 Docker，不必安装到 Mac 系统。

## 2. 检查命令

```bash
go version
node -v
npm -v
docker --version
docker compose version
git --version
python3 --version
gdalinfo --version
```

## 3. 建议但非第一期必需

- GDAL
- Python 3
- psql 客户端
- MinIO Client

## 4. 暂时不需要

- Kubernetes
- Kafka
- Elasticsearch
- Redis
- 独立向量数据库
- GPU
- 微服务注册中心

## 5. 推荐本地目录

```text
/Users/banq/Documents/history-map
```

解压文档后，在该目录继续创建前后端代码。

## 6. 后续环境初始化建议

```bash
cd /Users/banq/Documents/history-map

git init

cd frontend
npm create vite@latest . -- --template vue-ts

cd ../backend
go mod init history-map/backend
```

实际开始编码时再补充 Docker Compose 和初始化脚本。
